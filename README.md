# Role-Based Access Control System

Веб-приложение с системой разграничения прав доступа (RBAC), реализованное на Node.js. Проект включает три пользовательские роли, каждая из которых имеет доступ только к своим страницам благодаря строгой проверке безопасности.

## 🚀 Основные характеристики

* **Трехуровневая система ролей**: Уникальные интерфейсы и права доступа для Студента, Партнера и Администратора.
* **Безопасность (JWT)**: Авторизация реализована через JSON Web Tokens. Переход на страницу «чужой» роли невозможен из-за жесткой привязки токена на стороне сервера.
* **Защита данных**: Все пароли пользователей хранятся в зашифрованном (хешированном) виде.
* **База данных**: Интеграция с MongoDB для хранения данных пользователей, профилей и системных логов.
* **Демо-режим**: Наличие предустановленных аккаунтов для быстрого тестирования всех функций системы.

## 🛠 Технологический стек

* **Backend**: Node.js, Fastify (или Express).
* **Database**: MongoDB + Mongoose.
* **Security**: JWT (jsonwebtoken), Bcrypt (хеширование паролей).
* **Frontend**: HTML5, CSS3, JavaScript.
